加本地存档导出：界面上调的参数终于有出口了

起因：用户在网页界面上调了参数，问 push 一下。但界面上的改动全部存在
浏览器 localStorage 里（按构型分键：armBuilderModel:<id> / armBuilderCfg:<id> /
armBuilderView），不会进 git；而顶栏原来只有「保存 JSON」，只导出【模型】，
设置（装配位、底盘箱、显示开关、关节角…）没有任何出口。

现在加两个函数，都挂在 window 上（不做按钮，不挤顶栏）：
  exportLocalSettings()   -> 把 armBuilder* 开头的 localStorage 条目原样收集成对象
  downloadLocalSettings() -> 存成 armBuilder-存档-<configId>.json
浏览器控制台一句即可：downloadLocalSettings()

读的是【存档原文】而不是当前内存状态 —— 这样"导出的东西 == 你调出来的东西"
是硬的，不依赖导出时页面处于什么位形。

验证（无头 Edge）：两个函数都在、导出含 Cfg / Model / View 三类键，
字段齐（init / q / chassis / chassisV / sizer / modelCfg / configId）。
